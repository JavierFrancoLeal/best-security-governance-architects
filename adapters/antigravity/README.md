# Antigravity Adapter (`security-governance`)

Install into a workspace with:
```bash
bash adapters/install.sh --target antigravity --mode director-only --scope workspace --dest /path/to/repo
```
Installs `.agents/skills/security-director/` (1 active `SKILL.md` + non-recursive `references/` + `tools/`) and `.agents/rules/security-governance-bootstrap.md`.
