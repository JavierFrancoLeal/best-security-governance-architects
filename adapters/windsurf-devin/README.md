# Windsurf & Devin Adapter (`security-governance`)

Install into a workspace with:
```bash
bash adapters/install.sh --target windsurf --mode director-only --scope workspace --dest /path/to/repo
```
Installs `.windsurf/skills/security-director/`, `.windsurf/rules/security-governance-director.md`, and `.devin/rules/security-governance-director.md`.
